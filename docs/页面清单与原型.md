# CSUCampusCraft 页面清单与原型

本计划给出双端首个业务版本的页面结构、状态和界面变量。当前已交付范围与实测状态见 [README 的「当前阶段」](../README.md#当前阶段)和[《测试与验收用例》的实测记录](测试与验收用例.md)。下文保留全量业务页面规格。页面编号用于设计、任务和验收互相追踪，完整请求及写路由见[系统设计与路由](系统设计与路由.md)。

## 用户端页面

用户端使用 8080。公开页支持游客访问。登录后需按 [BR-01](需求与业务规则.md#br-01-身份与归属) 检查本端角色和数据归属。未认证时进入本端登录页，已登录但越权时显示拒绝页。

| 页面与读路由 | 访问及需求 | 内容与操作 | 空状态与错误 |
| --- | --- | --- | --- |
| U01 首页 `/` | 公开，REQ-01、REQ-02 | 站点导航、搜索、主题入口、毕业横幅、新品和精选。毕业横幅链接到 U02，并带毕业主题条件。 | 无主题时提示暂无主题。无可售商品时保留导航与搜索。目录查询失败显示重试入口。 |
| U02 商品列表 `/products` | 公开，REQ-02 | 主题、类型、关键词、排序、结果数量和分页。商品卡进入 U03。毕业专区复用同一页面并回显主题。 | 无匹配时给出清除条件。超出末页时保留过滤条件并提供返回有效页链接。参数不合法时指出输入，分类不存在时返回 404。 |
| U03 商品详情 `/products/{productId}` | 公开，REQ-03、REQ-05 | 面包屑、封面、相册、名称、SKU、价格、库存和纯文本设计说明。输入数量后加购，游客先登录。 | 无相册回退封面，资源缺失显示占位图。售罄显示库存状态并禁用加购。下架或不存在时返回可继续浏览的 404。 |
| U04 登录 `/login` | 公开，REQ-04 | 用户名、密码、登录按钮。成功回到允许的本端页面。 | 初始输入为空。错误账号、密码或角色采用统一失败文案，密码清空。会话过期时提示重新登录。 |
| U05 购物车 `/cart` | 本人 CUSTOMER，REQ-05 | SKU、现价、数量、库存提示、小计、数量更新、移除、整车结算。失效行保留并标注原因。 | 空车显示「去逛逛」。失效行阻止结算，可先移除。数量或旧版本冲突时提示重新读取最新购物车。 |
| U06 结算确认 `/checkout` | 本人 CUSTOMER，REQ-06、REQ-07 | 只读整车清单及金额、收货人、电话、完整地址和提交订单。显示模拟配送说明。 | 空车或失效车引导回 U05。字段错误就地标注。确认过期或车、价、库存变化时显示原因和重新确认入口。 |
| U07 本人订单列表 `/orders` | 本人 CUSTOMER，REQ-08 | 完整订单号查询、状态筛选、时间、金额和分页。 | 无订单提示返回商品列表，无匹配提供清除条件，非法查询返回参数错误。 |
| U08 本人订单详情 `/orders/{orderNo}` | 本人 CUSTOMER，REQ-07–REQ-10、REQ-13 | 主单状态、商品和收货快照、金额、状态时间及允许的操作。待支付时显示模拟支付和取消。启用 P1 时，已发货订单显示确认收货。 | 未知单号提示未找到。越权页省略订单详情。重复动作提示处理结果，冲突时显示最新状态。 |
| U09 模拟支付 `/orders/{orderNo}/payment` | 本人 CUSTOMER，REQ-09 | 明确标识教学模拟。展示订单号与成交金额，提供「模拟支付成功」「模拟支付失败」。 | 不可支付时说明当前状态并回订单。模拟失败返回待支付结果，可重试或取消。越权页省略金额及订单信息。 |

用户端所有业务页共用导航徽标。游客显示 0，当前启用的登录顾客显示本人所有 `cart_item.quantity` 的和，含下架、售罄或超库存行。它不表示商品种类数或有效行数。加购、改量、移除和下单清车成功后的目标页重新读取，其他已打开页面刷新后更新，失败不使用客户端推算修改徽标。公共页发现账号禁用或服务端身份标记变化时，清除旧身份并按游客显示，不泄露旧账号的车信息。

U02 使用 `categoryId`、`type`、`q`、`sort`、`page` 和 `size`。筛选变更回到第一页，翻页保留参数。类型展示为「全部」「文具」「纪念周边」，值为 `ALL`、`STATIONERY`、`SOUVENIR`。排序展示为「默认」「价格从低到高」「价格从高到低」「最新商品」，值为 `DEFAULT`、`PRICE_ASC`、`PRICE_DESC`、`NEWEST`。商品列表默认每页 6 条。

## 管理端页面

管理端使用 8081。业务版 A02–A10 要求已启用的 ADMIN。导航只呈现当前角色允许的操作，直接请求仍由服务端校验。

| 页面与读路由 | 访问及需求 | 内容与操作 | 空状态与错误 |
| --- | --- | --- | --- |
| A01 管理登录 `/login` | 公开，REQ-04 | 本端独立的登录表单与管理员身份说明。 | 初始输入为空。登录失败使用统一文案，密码清空。会话结束后提示重新登录。 |
| A02 控制台 `/` | ADMIN，REQ-01、REQ-04、REQ-14 | 当前管理员、上架数、草稿数、待发货数、普通顾客启用数与禁用数。卡片链接相应过滤列表，保留分类、商品、顾客、订单及退出入口。 | 空表显示 0。查询失败显示错误及重试，不以 0 代替。业务阶段需要管理员身份，用户端会话独立。 |
| A03 分类管理 `/categories`、`/categories/new`、`/categories/{categoryId}/edit` | ADMIN，REQ-11 | 两级分类列表、新增和编辑。新增二级时选择一级主题及类型，编辑编码和父类只读。删除前提示引用限制。 | 空列表显示「新建一级分类」。无可用父类时提示先建一级。有子类或引用时提示删除被拒绝，字段错误贴近输入。 |
| A04 商品列表 `/products` | ADMIN，REQ-11 | 分类、名称、状态查询，显示 SKU、现价、库存、上下架状态、编辑与相册入口。 | 空结果可清除条件或新建商品。操作后回到保留筛选的列表，当前状态变化时提示刷新。 |
| A05 商品表单与补货 `/products/new`、`/products/{productId}/edit` | ADMIN，REQ-11 | 新建填写 SKU、名称、分类、售价、文本介绍、封面和初始库存。编辑显示只读 SKU 与库存。补货单独输入增加数量。 | 无合法二级类目时提示先维护分类。校验失败保留可重填内容。旧版本提示刷新，商品不可用时返回 404。 |
| A06 订单列表 `/orders` | ADMIN，REQ-12、REQ-15 | 完整订单号、状态和可选顾客 ID 查询，显示顾客、时间、金额、状态及查看入口。 | 空结果提示清除条件。错误条件可修正后重试。 |
| A07 订单详情 `/orders/{orderNo}` | ADMIN，REQ-12 | 查看收货、商品快照、支付凭证和时间。仅待发货订单显示发货操作，提交前显示单号供核对。 | 未知单号返回 404。已发货的重复操作显示首次发货结果。待支付或已取消时说明状态门槛。 |
| A08 普通顾客列表 `/customers` | ADMIN，REQ-15 | 按用户名、状态查询并分页，显示 ID、用户名、显示名、启停状态、创建时间及详情入口。只显示 CUSTOMER。 | 无顾客或无匹配说明原因并保留筛选。参数错误可修改重试，查询失败显示重试入口。 |
| A09 普通顾客详情 `/customers/{userId}` | ADMIN，REQ-15 | 教学账号资料、启停表单和「查看该顾客订单」。禁用前提示后续保护请求失效及历史数据保留。 | 不存在或非 CUSTOMER 返回 404。提交后展示实际状态，重复同状态显示已处于目标状态，失败不显示成功。 |
| A10 商品相册 `/products/{productId}/images` | ADMIN，REQ-16 | 商品与独立封面摘要、有序相册、路径、替代文本和排序的新增、编辑、移除表单，表单带商品版本。 | 空相册提示前台回退封面并保留新增入口。缺图显示占位图。参数 400、归属 404、旧版 409，保留可修正输入并引导刷新。 |


## 用户端字段与操作反馈

| 页面 | 输入与展示 | 动作和结果 |
| --- | --- | --- |
| U01、U02 | 搜索框回显去除首尾空白的名称查询词。列表显示当前主题、类型、排序、分页及结果总数。商品卡显示封面、名称、单价和可售状态。 | 点击商品卡打开详情，修改筛选回第 1 页，点击分页保留其余条件。毕业横幅进入带毕业主题的同一列表。无有效毕业主题时保留通用入口。 |
| U03 | 数量默认 1，界面提示可售上限，展示名称、SKU、单价、封面及可选相册。 | 游客前往本端登录，成功后返回详情再手动加购。登录用户加购成功 303 进入 U05 并按全车数量和读取徽标。格式或数量范围错误 400，商品未知或下架 404，售罄、超库存、合并超 99 或第 21 种 SKU 409，均保留原车。会话无效先本端重登，错角色或 CSRF 403。页面给出对应字段、刷新详情或购物车入口。 |
| U04、A01 | 登录名和密码都有可见标签。校验失败可保留登录名，密码清空。 | 账户、密码、角色和状态不匹配使用同一提示。原目的地经本端校验后再返回，只允许读页。 |
| U05 | 每行显示当前单价、数量、有效小计、状态和更新、移除动作。改量、移除带该行版本。失效行指出下架、售罄或超当前库存。 | 失效行仍提供移除。全车可成交时才显示可用的整车结算入口。有失效行时标注「有效条目小计」，并解释处理完后才能结算。版本冲突从当前购物车重新加载，避免继续用旧版本提交。 |
| U06 | 只读整车和金额。表单填写收货人 1–50 字符、联系电话 1–30 字符、完整地址 1–255 字符，另带服务端确认令牌。 | 参数错误标注对应字段，保留可回显内容。确认过期、被另一个确认页替换或车价库存变化时，给出重新确认入口。空车或失效车引导回购物车。成功后进入新订单详情。 |
| U07、U08 | 列表的订单号、状态和页码均回显。详情使用下单时的商品、收货及金额快照，状态区按实际写入显示创建、支付、发货、取消及完成时间。 | 待支付显示支付及取消。取消前提示订单号和「库存会返还，商品不会放回购物车」。P1 启用后已发货显示确认收货。越权页不展示订单和收货数据。 |
| U09 | 显示本人待支付订单号和原成交金额，标注教学模拟。成功和失败两个按钮分别提交 `SUCCESS` 和 `FAILURE`。 | 模拟失败后回详情，说明仍待支付及可重试。成功显示待发货与首次支付凭证。已付订单重复成功显示原凭证，状态冲突引导回详情。 |

## 管理端字段与操作反馈

| 页面 | 字段和操作 | 反馈与恢复 |
| --- | --- | --- |
| A02 | 展示本端管理员身份及五张真实计数卡。上架含售罄，草稿按 DRAFT，待发货按 PAID，启停人数只计 CUSTOMER。卡片链接相同状态的列表，另有分类、商品、顾客、订单及退出入口。 | 所有数值来自同一查询时点。无数据为 0，查询失败显示错误和重试。登录失效回管理登录，直接读写仍鉴权。 |
| A03 | 列表按一级及其二级显示编码、名称、类型、排序。新建一级填写 1–21 字符编码、名称、排序，提示需保留最长 11 字符后缀，二级选择父主题和类型，由服务端生成编码。编辑只开放名称、排序。 | 删除前显示分类名称和限制。存在子类或商品引用时保留分类，提示先处理关联数据。重复编码、同父同名或重复类型显示冲突。 |
| A04 | 列表按分类、名称、状态筛选，展示 SKU、售价、库存、状态、编辑及相册入口和版本关联操作。草稿显示上架，已上架显示下架。 | 成功后刷新并保留有效筛选。过期版本或状态变化提示重新读取列表。上架且库存 0 显示「上架」和「售罄」。 |
| A05 | 新建填写 SKU、二级类目、名称、售价、摘要、详情、封面、初始库存和排序。封面空值使用占位图。编辑表单携带版本，SKU 和当前库存只读。补货用单独的正整数增量表单。 | 错误回显允许修改的字段。无二级类目先引导去 A03。补货前显示当前库存和本次增加量，提交成功展示数据库最新库存。旧编辑表单发生冲突时引导重新载入。 |
| A06、A07 | 列表以完整单号、状态和可选 `userId` 查询。从 A09 进入时回显「顾客 ID / 用户名」过滤标签并可清除。顾客 ID 必须为正整数且指向 CUSTOMER。详情展示主单、成交明细、收货与支付快照，只在待发货状态显示「模拟发货」。 | 发货前确认当前单号和收货信息，成功后详情展示首次发货时间。重复发货保留并显示首次结果。状态门槛不满足时说明当前状态，提供回订单入口。 |
| A08 | 查询词 `q` 去首尾空白后最多 50 字符，按用户名包含查询。状态 ALL、ENABLED、DISABLED，默认 ALL。每页默认 10 条，显示总数及 ID 升序结果。 | 查询变化回第 1 页，翻页保留条件。空结果可清除条件，不展示 ADMIN。详情入口指向 A09。 |
| A09 | 展示 ID、用户名、显示名、状态、教学邮箱、教学电话及创建时间，邮箱电话为空时显示「未填写」。不展示密码或散列。启停只提交 `targetStatus` 与 CSRF，订单入口为 `/orders?userId={id}`。 | 禁用先明确目标用户名和后果。首次或重复同状态 303 回本页，显示实际结果。禁用后已有用户端会话的下一次保护访问重登，启用后正常重新登录，原订单和购物车保留。 |
| A10 | 顶部展示商品名、SKU、当前版本、独立封面及返回 A04/A05 入口。列表按排序、ID 升序显示缩略图、路径、替代文本、排序。新增/编辑接收 `imagePath`、`altText`、`sortOrder`、`productVersion`，移除带 `productVersion`。 | 路径 1–255 字符且为 `images/` 站内相对路径，替代文本可空且最多 120 字符，排序非负且默认 0。旧版本 409 先刷新，错归属或未知图片 404，参数错误 400。实际变更增商品版本，成功回本页重读，不变的编辑成功但不增版。 |

A10 的图片操作仅维护相册行。末张移除前说明「详情将使用独立封面」，不会删除封面或素材文件。图片缺失展示占位图并保留路径供修正。所有相册表单都携带同一读到的商品版本，任一真实变更完成后重读全页更新其余表单的版本。首版不展示上传、裁剪、文件删除、账号创建、改密或角色调整入口。

提交时可显示「处理中」及当前动作，页面等待服务端结果后才更新订单状态和库存。重复点击保护依赖后端事务和状态约束。补货每次合法提交表示一笔增加量，界面要明确区分「重试之前先查结果」和「发起新的补货」。

## 页面状态约定

以下状态适用于上表每个页面。业务通过服务端渲染完成，请求等待和按钮反馈可以用渐进增强实现。

| 状态 | 呈现与交互 | 检查点 |
| --- | --- | --- |
| 正常 | 页面标题与当前位置明确。表格可读，主操作和次要操作有视觉层级。查询条件回显。 | 键盘能按可见顺序完成导航和表单。价格、库存及订单状态来自服务端。 |
| 加载或处理中 | 全页 GET 等待使用浏览器导航反馈。POST 可把提交按钮切到「处理中…」，保留可读标签。表单使用普通 HTML 时仍能提交。 | 连续点击的最终结果由服务端状态和事务保护。返回失败页后恢复可操作状态。 |
| 空 | 保留页面框架、筛选和上下文，用文字解释原因并给出下一步。 | 空车、无结果和全新后台可各自恢复，不展示无意义的空表。 |
| 参数或字段错误 | 指明错误字段和修复方式，错误摘要链接到字段。保留允许回显的输入。 | 标签与输入通过 `for/id` 对应，错误信息可被辅助技术关联。密码始终清空。 |
| 会话、越权或找不到 | 未登录进入本端登录页。越权 403 隐藏受保护数据。404 显示返回目录或列表入口。 | 双端 Cookie 互相独立，前端隐藏按钮后，后端仍会拒绝越权请求。 |
| 数据冲突或技术异常 | 409 显示冲突原因，提供刷新、重新确认或返回详情。技术错误用通用页面和本端返回入口。 | 失败界面不给出误导性成功反馈。重试由用户发起，刷新读页不重放表单。 |

订单标签统一显示「待支付」「待发货」「已发货」「已完成」「已取消」，与 [BR-08](需求与业务规则.md#br-08-订单状态机) 对应。商品状态使用「草稿」「上架」「售罄」，售罄标签取决于已上架且库存为 0。颜色只作辅助，状态文字始终可见。

## 低保真原型

### U01 与 U02 校园浏览

```text
U01  CSUCampusCraft     搜索商品 [________] [搜索]    登录    购物车
```

## 轻量界面变量

两端使用同一组基础变量，用户端突出校园图文和选购入口，管理端突出表格、筛选和确认反馈。变量名称是后续实现建议。

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `color-bg`、`color-surface` | `#F5F8F4`、`#FFFFFF` | 页面底色、卡片和表格面板 |
| `color-text`、`color-muted` | `#1C312A`、`#52655D` | 正文、辅助信息 |
| `color-primary`、`color-on-primary` | `#225B46`、`#FFFFFF` | 主操作、校园导航强调 |
| `color-border`、`color-focus` | `#D3DFD2`、`#1468AD` | 容器分隔和 2 px 键盘焦点线 |
| `color-success`、`color-warning`、`color-danger` | `#226644`、`#785300`、`#9F2929` | 成功、库存或待处理提示、错误与危险操作 |
| `font-family` | `system-ui, "Microsoft YaHei", "PingFang SC", sans-serif` | 系统字体优先 |
| `font-size` | 正文 16 px，辅助 14 px，页标题 28 px | 用一致字级表现层次 |
| `space`、`radius` | 4、8、12、16、24、32 px，圆角 8 px | 布局间距与卡片形状 |

桌面宽屏下保留商品网格和管理表格。较窄视口下筛选换行、表单双列收为单列，必要时允许表格容器横向滚动。以 Chrome 或 Edge 的 1366×768 和 1920×1080 检查主流程。占位图预留固定比例与替代文本，所有字段错误、库存提示和状态标签保留文字。素材来源、使用许可及校园名称见[需求与业务规则](需求与业务规则.md#初始商品分类)。
