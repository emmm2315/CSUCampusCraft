# CSUCampusCraft 项目立项与范围

CSUCampusCraft 是以中南大学地标和院系为题材的教学文创商城。项目交付两个可独立部署的 Spring Boot 应用，共用 MySQL。用户从校园主题或毕业专区选购现货，管理员维护分类、商品和相册，处理库存、普通顾客账号状态与发货，并用真实控制台核对运营待办。本轮起点为「M0 与 STEP02 已完成，业务模块待开发」；M0 的本地独立目录复现已归档，本轮公开目录覆盖见 STEP03 实测记录。

## 目标与使用者

| 使用者 | 首版目标 |
| --- | --- |
| 游客 | 按校园主题或商品类型发现文创商品，查看详情、价格和可售状态。 |
| 普通顾客 | 用教学账号登录，管理自己的购物车，填写收货地址、整车下单、模拟支付或取消待支付订单。 |
| 管理员 | 维护分类、商品、相册和库存，查询普通顾客及其订单，启停普通顾客账号，查询全站订单并登记发货，用控制台核对上架、草稿、待发货及顾客状态数量。 |
| 开发与验收人员 | 用共享 SQL 重建测试库，复现双端启动和从上架到发货的流程，并拿到库存、订单和权限证据。 |

项目特色是毕业专区和独立成品礼盒。毕业专区复用主题商品列表。礼盒按盒定价、补货、扣减和返库，盒内单品保留各自库存。五个初始主题和首批商品见[需求与业务规则](需求与业务规则.md)。

## 首版纳入范围

- **M0 工程初始化。** 双端独立 Maven 构建，共用 MySQL，根页读取数据库主题。结构版与演示版 SQL 可在空库分别导入，共享静态图片可从两个端口加载。对应 REQ-01。
- **P0 浏览与身份。** 首页、两级分类、毕业专区、名称搜索、排序、服务端分页、详情和相册读取。普通顾客与管理员各有登录会话。对应 REQ-02–REQ-04。
- **P0 交易。** 持久购物车、整车结算、成交快照、原子下单、本人订单查询、模拟付款和待支付取消返库。履约使用收货地址，后台登记模拟发货。对应 REQ-05–REQ-10。
- **P0 运营。** 管理端维护两级分类、商品资料与独立相册，执行上下架和增量补货。查询普通顾客、查看其订单并启停普通顾客账号，查询全站订单和登记发货。控制台展示数据库中的商品状态、待发货及普通顾客状态数量。对应 REQ-11–REQ-12、REQ-14–REQ-16。三个新增需求均纳入首版必做，仍处于设计阶段。
- **P1 候选。** 普通顾客确认收货。P0 通过后由小组选做，启用时同时验收，详见 REQ-13。

## 首版排除范围

| 主题 | 后续议题 |
| --- | --- |
| 履约与支付 | 校内自提、真实支付、退款售后、物流单号与轨迹、运费。 |
| 商品与营销 | 多规格、个性化定制、组合实时拆库存、优惠券、收藏、销量统计、销售额及财务报表。首版控制台只统计当前业务状态。 |
| 账号与内容 | 自助注册、验证码、第三方或校园统一认证、顾客资料编辑、改密、密码重置、管理员账号管理、角色调整、图片上传及静态文件删除。首版仅管理已有普通顾客的启用状态，并维护相册记录。 |
| 交付形态 | 独立前端、移动端专项适配、开放 REST 接口、跨库支持和生产部署。REST 映射作为设计预留。 |

## 双端业务闭环

| 用户端能力 | 管理端支撑与核对 | 首版边界 |
| --- | --- | --- |
| 主题导航、筛选和毕业专区 | 创建两级分类、维护排序，新增主题后前台可直接查询。 | 仍使用两级主题与商品类型，不新增分类体系。 |
| 商品详情、相册和售罄提示 | 维护商品资料与封面，独立维护相册顺序、替代文本，执行上下架及增量补货。 | 相册维护只写现有 `product_image`，素材仍在仓库统一维护。 |
| 普通顾客登录和本人数据 | 查询普通顾客，查看其订单，启用或禁用账号。禁用提交后已有会话的后续保护请求失效。 | 保留购物车、订单和历史收货快照，不提供改密、角色变更或账号删除。 |
| 模拟支付后的配送等待 | 按状态、完整单号及顾客查单，核对收货快照后登记模拟发货。 | 后台不能替顾客付款、取消或确认收货，不录入真实物流。 |
| 商品与订单状态变化 | 控制台读取上架、草稿、待发货和顾客启停数量，链接对应过滤列表。 | 不把教学支付金额汇总为真实营业额，不使用固定数字充当统计。 |

## 项目约束

- MySQL 8.4（InnoDB）是正式数据库基线，两个工程使用同一个库和七张业务表。底层回归环境以[实测记录](测试与验收用例.md#初始化实测记录)为准。
- Spring MVC、Thymeleaf、MyBatis-Plus 和 Java 17 编译目标沿用当前初始化工程。页面由服务端渲染，两个应用分别管理会话。
- 商品、价格、地址和账号均用于课程演示。校园素材记录来源和使用许可，源码库使用站内资源与教学数据。

| P0 业务 | REQ-02–REQ-12、REQ-14–REQ-16 及关联 BR 的必做用例全部通过。主流程从分类、商品、相册维护到上架、加车、下单、模拟支付及发货。另测顾客启停与会话失效、真实统计、相册归属及版本、失败回滚、越权、旧确认和并发库存。 |

| 交付复现 | 组员能用 README、空数据库和项目 SQL 复现启动与演示。验收结果标明测试版本、环境和实际证据。 |

用例与历史证据见[测试与验收用例](测试与验收用例.md)。调整范围时，由小组在[开发计划与任务](开发计划与任务.md)中登记决定和负责人，并同步影响到的需求、页面、路由、数据库和测试。
